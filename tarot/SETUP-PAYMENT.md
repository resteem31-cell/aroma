# 카카오 로그인 · 카카오페이 결제 설정 안내

타로 사이트는 결제 기능이 켜진 곳에서만 돈을 받습니다. 결제 기능은 Cloudflare Pages에 올렸을 때 켜지고, GitHub Pages 주소에서는 지금처럼 무료로 동작합니다.

## 가격
| 주제 | 가격 |
|---|---|
| 연애운 | 3,900원 |
| 재회운 | 3,900원 |
| 진로운 | 2,900원 |
| 선택의 기로 | 1,800원 |

가격은 `tarot/_server/common.js`의 `PRICES`에서 바꿉니다. 화면에 보이는 가격도 여기서 읽어 옵니다.

## 손님이 겪는 흐름
1. 주제를 고르고 버튼을 누르면 카카오 로그인 화면이 열립니다. 로그인하면 회원으로 기록되고, 고른 주제와 질문은 그대로 남아 있습니다.
2. 결제 버튼을 누르면 카카오페이 결제 화면이 열립니다.
3. 결제가 끝나면 사이트로 돌아와 다섯 장 중 한 장을 고르고 11장 풀이를 봅니다.
4. 결제 한 번에 카드를 한 번 뽑을 수 있습니다. 뽑은 카드는 저장되므로, 결제 후 받은 주소(`?order=...`)로 들어오면 같은 풀이를 다시 볼 수 있습니다. 다시 볼 때는 결제한 카카오 계정으로 로그인해 있어야 합니다.

## 1. 카카오 개발자 사이트 (로그인)
https://developers.kakao.com 에서 로그인한 뒤 진행합니다.
1. 내 애플리케이션 → 애플리케이션 추가하기 (앱 이름 예: Light the Way)
2. 앱 키에서 **REST API 키**를 복사해 둡니다.
3. 플랫폼 → Web → 사이트 도메인에 새 주소를 등록합니다 (예: `https://lighttheway.pages.dev`).
4. 카카오 로그인 → 활성화 ON, Redirect URI에 `https://새주소/api/auth/callback` 을 등록합니다.
5. 동의항목에서 **닉네임**을 필수 동의로 설정합니다.
6. (선택) 보안 → Client Secret을 켰다면 그 값도 복사해 둡니다.

## 2. 카카오페이 개발자 사이트 (결제)
https://developers.kakaopay.com 에서 진행합니다.
1. 가입 후 내 애플리케이션에서 앱을 만들고, **Secret key(dev)** 를 복사합니다. 이 키로는 테스트 결제만 되고 실제 돈은 빠져나가지 않습니다.
2. 앱 설정의 웹 도메인에 새 주소를 등록합니다.
3. 실제 판매를 시작하려면 카카오페이 **가맹점 신청**을 합니다(사업자등록증 필요). 심사가 끝나면 받는 **CID**와 **Secret key(prod)** 로 바꿔 넣으면 실결제가 시작됩니다.
4. 가맹 심사에서는 보통 사이트에 사업자 정보, 환불 규정, 이용약관, 개인정보처리방침이 있는지 확인합니다. 필요하면 이 페이지들도 만들어 드릴게요.

## 3. Cloudflare Pages (사이트와 결제 서버)
https://dash.cloudflare.com 에 가입한 뒤 진행합니다.
1. Workers & Pages → 만들기 → Pages → Git에 연결 → `resteem31-cell/aroma` 저장소 선택
2. 프로덕션 브랜치 `main`, **루트 디렉터리 `tarot`**, 빌드 명령은 비워 둡니다.
3. Workers & Pages → KV → 네임스페이스 만들기 (이름 예: `tarot-orders`)
4. 만든 Pages 프로젝트 → 설정 → 바인딩 → KV 네임스페이스 추가, 변수 이름 **`ORDERS`**, 위에서 만든 네임스페이스 선택
5. 설정 → 변수 및 비밀(Variables and Secrets)에 아래 값을 넣고, 비밀값은 '암호화'로 저장합니다.

| 이름 | 값 |
|---|---|
| `KAKAO_REST_KEY` | 카카오 REST API 키 |
| `KAKAOPAY_SECRET_KEY` | 카카오페이 Secret key (테스트는 dev, 실결제는 prod) |
| `SESSION_SECRET` | 아무도 모르는 긴 임의 문자열 (40자 이상) |
| `KAKAOPAY_CID` | 실결제 때만 가맹점 CID. 비워 두면 테스트용 `TC0ONETIME` |
| `KAKAO_CLIENT_SECRET` | (선택) 카카오 Client Secret을 켰을 때만 |
| `SITE_URL` | (선택) 도메인을 연결했다면 `https://내도메인` |

6. 값을 넣은 뒤 배포를 한 번 다시 실행합니다(배포 → 다시 시도).
7. 도메인을 샀다면 Pages 프로젝트 → 사용자 지정 도메인에서 연결하고, 카카오 두 곳의 도메인과 Redirect URI도 그 주소로 바꿉니다.

## 테스트 결제 모드
`KAKAOPAY_CID`를 비워 두면 화면 위쪽에 '테스트 결제 모드'라고 표시되고, 카카오페이 테스트 결제가 진행됩니다. 실결제로 바꾸면 이 표시가 사라집니다.

## 알아 둘 점
- 결제 금액은 서버가 가격표로 정하고, 승인할 때 카카오페이가 알려 준 금액과 다시 맞춰 봅니다. 화면에서 금액을 바꿔도 결제 금액은 바뀌지 않습니다.
- 카드 의미 문장(`data.js`)은 브라우저가 풀이를 만들 때 쓰므로 공개되어 있습니다. 개발 지식이 있는 사람은 결제 없이 문장을 읽어 볼 수 있지만, 일반 손님은 결제해야 풀이를 봅니다.
- 주문과 회원 기록은 Cloudflare KV에 저장되고, 주문은 90일 뒤 자동으로 지워집니다. 결제 내역 원본은 카카오페이 가맹점 관리자에서 볼 수 있습니다.
