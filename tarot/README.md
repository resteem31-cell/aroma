# Light the Way (11장 타로)

- 주소: https://resteem31-cell.github.io/aroma/tarot/
- `index.html`(화면·풀이 규칙) + `data.js`(78장 카드 의미) + `cards/`(카드 그림)로 동작합니다. 서버 없이 브라우저에서 풀이를 조합합니다.

## 흐름
주제 고르기(연애운·재회운·진로운·선택의 기로) → 78장을 섞어 부채꼴로 펼침 → 다섯 장 중 한 장 선택 → 고른 카드가 1번 자리에 놓이고, 섞인 덱에서 그 카드 뒤로 이어진 10장이 자동으로 2~11번 자리에 놓임 → 자리별 풀이.
선택의 기로는 A, B 선택지마다 다섯 장 중 한 장을 고르고 각각 11장이 펼쳐집니다(B는 A에 쓰인 카드를 뺀 덱에서).
역방향은 약 30% 확률로 나옵니다.

## 11장 자리
- 연애운·재회운: 현재 상황(1·2) · 상대방의 속마음(3·4) · 나의 속마음(5·6) · 내가 원하는 것(7) · 앞으로 어떻게 되는지(8·9) · 조언(10) · 새길 말(11)
- 진로운: 현재(1) · 좋아하는 것(2) · 힘들어하는 부분(3) · 극복해야 할 점(4) · 배우면 좋은 점(5) · 해결해야 할 것(6) · 준비해야 할 것(7) · 앞으로의 흐름(8·9) · 조언(10·11)
- 선택의 기로(A·B 각각): 현재 상황(1) · 이런 상황이 된 이유(2·3) · 원하는 것(4·5) · 해결 방법(6·7) · 앞으로의 흐름(8·9·10) · 조언(11)

풀이 분량은 연애운·재회운·진로운 기준 공백 포함 약 13,000~14,500자(공백 제외 약 10,000자 이상)입니다.

## 문구 수정
- 카드 의미: `data.js`의 각 카드 `up`(정방향), `rev`(역방향) 안의 core / love / partner / self / career / choice / future / advice / word.
- 자리 이름과 설명: `index.html`의 `TOPICS`, 자리별로 읽는 문장 종류는 `FIELDS`, 자리별 질문은 `REFLECT`, 섹션 정리 문장은 `WRAP`.
- 흐름 지수(관계 온도 등)의 카드별 밝기 값은 `VAL`.

## 카드 그림
라이더-웨이트 타로(Pamela Colman Smith 그림, 1909년 출간) 스캔본으로, 미국 기준 퍼블릭 도메인입니다. 판매용으로 쓸 때는 판매 국가의 저작권 기준을 한 번 확인하세요.
